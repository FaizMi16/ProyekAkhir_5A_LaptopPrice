## Cara Menjalankan
1. Buka `notebook/01_eksplorasi.ipynb` menggunakan Google Colab atau Jupyter Notebook.
2. Pastikan file `laptop_price.csv` berada di direktori yang sama (atau upload manual jika pakai Colab).
3. Jalankan semua cell dari atas ke bawah (Run All).
4. Data bersih akan tersimpan sebagai `data/data_bersih_laptop.csv`.
